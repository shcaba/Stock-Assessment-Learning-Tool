# Stock Assessment Learning Tool (SALT)

A variety of interactive applications to learn about stock assessment inputs and outputs.
The learning modules will continue to grow. If you have idea, add them to the issues or reach out to Jason Cope (jason.cope@noaa.gov)

Access the Stock Assessment Learning Tool directly here: [https://connect.fisheries.noaa.gov/SALT/](https://connect.fisheries.noaa.gov/SALT/)
